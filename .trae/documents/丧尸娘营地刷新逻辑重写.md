# 新版丧尸娘营地：覆盖结构并重写刷新逻辑

## 背景

玩家提供了重新制作的新版营地结构 `zombie_girl_camp.nbt`（34×10×34），需要用它替换模组内旧结构，并让生成/刷新逻辑适配新结构。

新结构与旧结构的差异直接决定了几处必须改的地方：

| 项目 | 旧结构（现有代码假设） | 新结构（实测 NBT） |
| --- | --- | --- |
| 尺寸 | 较小 | 34 × 10 × 34 |
| 第 0 层 | 地基 | 泥土填充（含 1 格 structure_block） |
| 第 1 层 | — | 草地 / 木板道路（地表层） |
| 第 2 层 | 室内地面 | 室内地面（床、木桶、工作台均在此层） |
| 屋顶 | — | 第 5~7 层（羊毛 / 楼梯 / 半砖） |
| 容器 | 少量箱子 | 24 木桶 + 8 熔炉类（自带 `Items` 为空） |
| 床 | — | 8 张（均在相对 Y=2） |
| 导出残留 | 无 | `minecraft:structure_block` 位于相对 (0,1,0) |

现有代码有三处与新结构冲突：

1. **原点**：`surface`（地表高度图，即第一格空气）被直接当作结构最小角，新结构会把地基压到地表以上，草地层悬空。
2. **地面搜索**：`FLOOR_SCAN_HEIGHT = 6`、`CAMP_INTERIOR_HEIGHT = 4`，且第 4 层才是旧结构的室内地面；新结构第 2 层就是地面，若沿用会扫到家具或屋顶。
3. **structure_block**：旧结构没有该方块；新结构若原样放置会把结构方块带进世界。

## 目标

- 用新 NBT 覆盖 `src/main/resources/data/endbound_ember/structures/zombie_girl_camp.nbt`。
- 放置时结构原点 = 地表高度图 `G` 再下移 1 格（`origin.y = G - 1`），使结构草地层正好落在 `G`、室内地面落在 `G + 1`，整座营地成为高出周围一格、内部不会被地形穿插的平台。
- 重写地面判定、容器填充、少女生成与营地记录，使它们都以新结构的实际分层为准。
- 保留原有约束：群系/水源/农田拦截、出生点营地、营地互斥、存档去重、测试指令。

## 实现方案

### 1. 替换结构文件

用玩家提供的 `zombie_girl_camp.nbt` 覆盖：

`src/main/resources/data/endbound_ember/structures/zombie_girl_camp.nbt`

代码通过 `level.getStructureManager().get(...)` 与 ResourceManager 两条路径加载同一路径，无需改路径。

### 2. `ZombieGirlCampEvents` 重写

新增常量：

```java
/** 结构原点（最小角）相对地表高度图的下移格数：草地层替换原地表，室内地面高出周围一格。 */
private static final int ORIGIN_Y_OFFSET = -1;
/** 结构第 2 层是室内可站立地面（第 1 层为草地/木板）。 */
private static final int CAMP_FLOOR_LAYER = 2;
/** 室内净高上限：超过该相对层视为屋顶。 */
private static final int CAMP_INTERIOR_HEIGHT = 4;
/** 营地常驻少女数量（新营地有 8 张床）。 */
private static final int CAMP_GIRL_COUNT = 6;
```

关键改动：

- **水平居中**：营地以区块中心（`chunk.getMinBlockX() + 8`）为中心，原点水平偏移 `-size/2`，避免 34 格宽结构偏向一侧。
- **垂直原点**：`origin = surface.offset(-sizeX / 2, ORIGIN_Y_OFFSET, -sizeZ / 2)`。
- **放置设置**：加 `BlockIgnoreProcessor.STRUCTURE_BLOCK`，忽略导出残留的结构方块；放置后对 `template.filterBlocks(...)` 找到的结构方块位置补回 `grass_block`，避免地面出现 1 格空洞。
- **农田检查**：范围改为从 `origin.below()` 到 `origin + size - 1`（原点已下移 1 格，无需再多扫 2 格）。
- **营地互斥**：统一以营地中心比较（`campCenter = origin + (sizeX/2, CAMP_FLOOR_LAYER, sizeZ/2)`），保留 `对角线 + CAMP_GAP` 的间距算法；出生点营地保留位置同样改为区块中心。
- **容器填充**：逻辑不变（仍是 `RandomizableContainerBlockEntity` + 现有战利品表），新营地 24 个木桶自带 `Items` 为空，不需要额外清理。
- **少女生成**：
  - 从相对第 2 层开始扫描，最多扫到第 4 层；
  - 增加“可站立底面”判定（`BlockTags.DIRT` / `BlockTags.PLANKS` / 石砖 / 平滑石），避免少女刷在木桶、铁砧、工作台、床等家具上；
  - 保留耕地/作物跳过与水鬼需要水面的分支；
  - 数量改为 `CAMP_GIRL_COUNT = 6`。
- **测试指令** `placeCampAt`：改为 `center.offset(-sizeX/2, ORIGIN_Y_OFFSET, -sizeZ/2)`，与自然生成同一套原点规则；玩家执行后会站在室内地面上。
- 删除从未使用的 `LOOT` 常量与对应导入。

### 3. `ZombieGirlCampSavedData`

- 记录值语义由“结构角 + 高度”改为**营地中心**（含室内地面 Y），`locate camp` 传送点因此落在营地中央地面。
- 无需改存储格式，旧存档中的旧坐标仍可作为普通点参与距离比较。

### 4. `ZombieGirlSpawnEvents`

- `CAMP_EXCLUSION_RADIUS` 24 → 26：新营地半对角线约 24.04 格，24 会漏掉四角，补刷仍可能刷进营地。

## 验证

1. `.\gradlew.bat build` 编译通过。
2. 新建世界进入游戏，使用 `/endbound summon camp`（权限 2）在当前位置放置：
   - 营地完整出现，结构方块没有残留；
   - 玩家站在室内地面上，四周草地与本营地齐平；
   - 木桶内有战利品，营地里生成 6 只少女且没有卡在床上/屋顶/家具上。
3. `/endbound locate camp` 给出的坐标位于营地中心地面。
4. 自然生成：走到候选区块，确认营地生成、没有与出生点营地重叠、农田/水源/海洋旁被正确拦截。
5. 旧存档需删除 `data/endbound_ember_zombie_girl_camps.dat` 才会重新生成营地（现有日志已提示）。
