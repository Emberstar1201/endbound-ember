# 更好的砂轮与铁砧机制配置计划

## Context

用户希望砂轮对单个附魔物品执行去魔时，除原版产物外，再额外生成一本包含该物品完整原有附魔集合的附魔书；砂轮双输入合并维持原版行为。铁砧增强和砂轮增强需分别提供配置开关，默认都开启，并可在配置中关闭。

## 当前状态分析

- 项目目标为 Minecraft 1.21.1 / NeoForge 21.1.262。
- `Config.java` 集中定义配置项；现有布尔机制配置默认 `true`。
- `AnvilMechanicsMixin.java` 已包含免费改名、取消过贵上限、减少损耗等 5 个注入/重定向，目前尚无总开关。
- `endbound_ember.mixins.json` 已注册铁砧 Mixin，但未注册砂轮 Mixin。
- `GrindstoneMenu` 原版有两个输入槽；单输入路径会移除非诅咒附魔，双输入是合并/修复的另一分支。结果槽取出回调 `Slot.onTake` 在清空输入之前运行，适合只在真实取走结果时结算奖励。
- 配置界面本地化沿用 `endbound_ember.configuration.<key>` 和 `endbound_ember.configuration.<key>.tooltip`，需覆盖英文、简体中文、繁体中文（台湾）、繁体中文（香港）四种语言。

## 拟议修改

1. **配置开关** — 修改 `src/main/java/com/emberstar/endbounember/Config.java`，新增独立的铁砧机制与砂轮去魔附魔书机制布尔项，均默认 `true`。
2. **铁砧开关接入** — 修改 `src/main/java/com/emberstar/endbounember/mixin/AnvilMechanicsMixin.java`，使现有五个增强点逐一受铁砧配置控制。关闭时注入不改变原版结果；常量修改返回原值；两个重定向分别原样调用原版经验扣除和原版 `CommonHooks.onAnvilRepair`。
3. **砂轮奖励** — 新增 `GrindstoneMenu` Mixin，只在服务端、砂轮开关开启且结果确实由唯一一个有可去除附魔的输入物品产生时，在结果槽 `onTake` 中创建并发放附魔书。先复制输入附魔数据再由原版继续清空输入。把 `DataComponents.ENCHANTMENTS` 中的完整 `ItemEnchantments` 写入 `Items.ENCHANTED_BOOK` 的 `DataComponents.STORED_ENCHANTMENTS`。背包放不下时将书掉落，避免奖励丢失；双输入合并、空附魔输入、只有诅咒且无可去除附魔时不发书。
4. **Mixin 注册** — 修改 `src/main/resources/endbound_ember.mixins.json`，在公共 Mixin 列表登记新的砂轮 Mixin。
5. **配置本地化** — 在以下四份语言文件加入两个配置名称及 tooltip：
   - `src/main/resources/assets/endbound_ember/lang/en_us.json`
   - `src/main/resources/assets/endbound_ember/lang/zh_cn.json`
   - `src/main/resources/assets/endbound_ember/lang/zh_tw.json`
   - `src/main/resources/assets/endbound_ember/lang/zh_hk.json`

## 假设与决定

- 砂轮仅有一个输入物品时才会生成额外附魔书，双输入行为不变。
- “完整原有附魔集合”按字面处理，原样保留附魔及等级（包括诅咒）；但若没有任何可被原版砂轮去除的非诅咒附魔，则不产生额外书，防止仅诅咒输入产生重复奖励。
- 奖励只在服务端实际取走砂轮输出时产生，不在预览、输入改变或客户端预测时发放；服务端结果槽 `onTake` 是唯一发放时机。
- 铁砧与砂轮开关互相独立，默认均开启。
- 背包满时允许掉落附魔书。

## 验证

- 运行 `./gradlew.bat compileJava --offline`，验证配置引用、Mixin 注入目标及类型兼容。
- 运行客户端并检查启动日志，确认新 Mixin 成功加载且没有注入失败。
- 默认设置下验证：单输入多附魔物品取出砂轮结果后恰好得到一本含全部原附魔及等级的附魔书；原版去魔产物仍正常；双输入合并不额外产书。
- 验证无附魔及仅诅咒输入不会产书；背包有空间时附魔书入包，背包满时掉落。
- 分别关闭配置项验证隔离：关闭铁砧开关后，免费改名、过贵上限、经验费用及损耗概率恢复原版；关闭砂轮开关后不再额外产书，另一机制仍启用。
- 检查四份语言 JSON 格式有效且配置名称与 tooltip 键齐全。
