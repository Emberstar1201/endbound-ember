# 长矛移植计划

## Context

将 `Unknowneth/Backported-Spears` 中适用于 Minecraft 1.21.1 的长矛行为与必要资源移植到本项目 NeoForge 1.21.1。优先实现上游蓄力、速度驱动的冲刺攻击；若在目标版本无法稳定适配，则退化为三叉戟式投掷。移植应避免原样搬入上游 Fabric/Yarn 和广泛 Mixin 集成，并确保长矛不误触本项目剑格挡逻辑。用户要求保留上游仓库地址、作者署名及原始 CC0 许可文件，并明确指出之前移植的祛魔台也必须保留原仓库链接和原仓库许可证文件。

需求中的“1.21.11”与仓库已核实的 `1.21.1` 分支不一致。实施前应确认目标指的是上游 `1.21.1` 代码；如确实指另一个版本，先核实对应上游代码来源再开始。

现有 `THIRD-PARTY-NOTICES.md` 已记录祛魔台来源 `Cursee-Development/Dis-Enchanting-Table` 的 1.21.1 分支、作者/组织、仓库链接与 Unlicense 链接，但未收录完整原始许可证文件；实施时需补齐，不能只留许可证 URL。

## 实施步骤

1. 核实两个上游仓库的目标分支及许可原文，并确认可直接复用的代码/资源范围。为长矛保留上游原始 CC0 LICENSE 文件；为祛魔台保留上游原始 Unlicense 文件。继续在现有 `THIRD-PARTY-NOTICES.md` 分别记载作者/组织、仓库 URL、分支、许可和实际采用范围。项目现有 GPL-3.0-or-later 声明不替代任何上游许可证，也不得将两份上游许可混写或改写。
2. 在 `EndboundEmber.java` 注册长矛、属性和创造栏条目；新增独立长矛物品行为，不复用剑的业务逻辑。长矛不加入 `ItemTags.SWORDS`，确保 `world/SwordBlocking.java` 及剑格挡 Mixin 不会将其视为剑。
3. 优先按上游思路实现蓄力/速度驱动冲刺：服务端权威判断蓄力、速度、方向、目标碰撞、伤害、击退和冷却；仅在确实需要时使用项目现有 payload/Mixin 模式，并验证 Mixin 目标适配 1.21.1。若无法可靠实现，则采用服务端权威的三叉戟式投掷作为替代攻击，不无故同时增加两种模式。
4. 补齐长矛配方、物品模型与纹理引用、四种语言名称，以及必要音效；沿用铜剑配方/模型、语言文件和 `sounds.json` 的本地格式。仅在有自定义音效时新增音频资源。
5. 运行 Gradle 构建并启动客户端验证注册与资源；检查长矛攻击、蓄力/投掷、目标去重与冷却、攻击中断、多人同步及与剑格挡/双持行为的隔离。最后核对上游 URL、作者、原始 CC0 文件均完整保留。

## 关键文件

- `src/main/java/com/emberstar/endbounember/EndboundEmber.java`：物品、创造栏及可能的网络 payload 注册。
- `src/main/java/com/emberstar/endbounember/world/SwordBlocking.java`：确保长矛不参与剑格挡。
- `src/main/resources/endbound_ember.mixins.json`：仅在实现确有需要时扩展。
- `THIRD-PARTY-NOTICES.md`：分别记录长矛与祛魔台的来源、作者/组织、仓库 URL、分支、许可及采用范围。
- 根目录保留长矛上游原始 CC0 LICENSE 和祛魔台上游原始 Unlicense 文件，保持原文，不以项目 GPL 文件替代。
- `src/main/resources/data/endbound_ember/recipe/`、`assets/endbound_ember/models/item/`、`assets/endbound_ember/lang/`、`assets/endbound_ember/sounds.json`：按需添加长矛资源。
- 参考既有物品属性模式 `item/SwordOfTheFreeWillItem.java`、铜剑配方与模型、`world/FlywheelDash.java` 及 `network/FlywheelDashPayload.java`；仅复用适用模式，不直接带入剑气或冲刺无敌效果。

## 验证

- Gradle 构建检查 Mojmap/NeoForge API、JSON 资源及 Mixin 注入目标。
- 开发客户端启动确认无注册、模型、语言、声音或 Mixin 错误。
- 实测未蓄力与蓄力冲刺（或降级投掷）、不同移动速度、命中实体/方块、冷却与打断；验证多人环境服务端裁决，不接受客户端伪造攻击参数。
- 验证长矛不触发剑格挡，现有剑格挡和双持行为不回归。
- 检查 `THIRD-PARTY-NOTICES.md` 中两个项目的仓库链接、作者/组织、许可及采用范围，确认 CC0 LICENSE 与 Unlicense 原始文件均完整保留。
