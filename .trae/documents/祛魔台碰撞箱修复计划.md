# 祛魔台碰撞箱修复计划

## Context

用户指出祛魔台碰撞箱应与原版附魔台一样大小，并澄清视觉上应有原版附魔台顶部的动态书。检查发现祛魔台方块没有自定义形状，默认碰撞箱为完整 16×16×16；静态方块模型已是 16×12×16 的矮台但没有书，项目也没有祛魔台专用书本渲染器。目标是保留现有底座模型，为其增加原版样式动态书，并修复碰撞形状。

## 实施步骤

1. 在 `DisenchantmentTableBlock.java` 定义 16×12×16 的 `VoxelShape`，用于方块选择和碰撞形状，与原版附魔台底座一致。
2. 在 `DisenchantmentTableBlockEntity.java` 增加仅客户端使用的原版风格书本动画状态及客户端 ticker，保留现有服务端自动祛魔逻辑。
3. 新增 `DisenchantmentTableRenderer.java`，复用原版 `BookModel`、`ModelLayers.BOOK` 和附魔台书本纹理，在现有矮台底座上渲染动态书。
4. 在 `ModClientEvents.java` 的方块实体 renderer 注册处注册新 renderer。保留静态底座模型、物品模型和纹理，不在物品栏模型中添加动态书。
5. 运行 Gradle 构建与 `git diff --check`；游戏中与附魔台并排，用 F3+B 检查相同的 12/16 高碰撞箱，并检查书本显示/朝向/开合动画、菜单交互与破坏掉落。
