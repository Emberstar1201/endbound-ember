# 加速火把倍率配置与墙面放置方案

## Context

用户希望直接在配置中调整加速火把倍率，并让加速火把可以像火把一样插在方块侧面。倍率配置 `acceleratorTorchSpeed` 已存在，范围 1–8、默认 2，且加速逻辑运行时读取；语言文件也已有对应配置名称和说明。因此不新增重复配置键，重点保留现有文本并实现墙面放置。

## 实施方案

1. 保留 `Config.java` 中现有 `acceleratorTorchSpeed` 配置及四种语言文本，不重写或格式化这些文件；验证其配置文件键、范围、默认值和运行时读取路径。
2. 在 `AcceleratorTorchBlock` 加入水平 `FACING` 状态，保持既有方块 ID、物品、方块实体类型和 ticker 不变，避免存档迁移。
3. 扩展放置逻辑：底面仍按既有规则落地放置；点击水平面时将火把贴在该墙面，朝向与墙面/模型约定一致；顶面点击不新增倒挂行为。对墙面支撑失效沿用方块更新移除行为。
4. 调整支撑检测、方块形状与火焰/烟雾位置以适配朝向；不改加速范围与随机刻/方块实体加速机制。
5. 扩展方块状态资源，为四个水平朝向指定 `minecraft:block/template_wall_torch` 模型变体，保留地面状态现有 `template_torch` 模型，并继续使用加速火把本地贴图和 cutout 渲染。
6. 仅在确有缺失时逐条补充语言条目，保持四份现有语言文件其余内容和格式不变。

- `src/main/resources/assets/endbound_ember/blockstates/accelerator_torch.json`

- `src/main/java/com/emberstar/endbounember/block/AcceleratorTorchBlockEntity.java`（只读确认倍率读取路径，原则上不修改）

## 验证

- 运行 `./gradlew.bat compileJava --no-configuration-cache -q` 并校验 JSON。
- 游戏内检查地面放置及四面墙侧放、墙面支撑破坏、模型和粒子方向、加速火把方块实体 ticker、保存重载状态。
- 在配置文件中调整 `acceleratorTorchSpeed`，确认范围内随机刻及方块实体加速使用新倍率。
- 确认四种语言文件未被重写，现有配置文本仍完整。
