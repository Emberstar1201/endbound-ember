# 基岩走搭与墙跳内置机制计划

## Context

为末地等危险地形探索增加两项可分别关闭的内置移动机制：参考 Bridging mod 辅助空中桥接放置方块，并参考 Wall-Jump TXF 在空中贴墙时通过按住 Shift 进行墙跳。墙跳的 Shift 键应可在按键设置中重绑。

## 实施方案

1. 在 `Config.java` 中增加走搭与墙跳两个独立布尔配置及中文/繁体中文/英文本地化条目；两者默认开启，互不依赖现有移动机制总开关。
2. 走搭作为原版右键放置的空中辅助：保留原版使用键操作，在空中桥接时辅助识别目标方块下方/相邻的合法附着面并放置方块。仍执行原版放置距离、方块碰撞、保护规则和物品消耗；不可放置时不消耗物品、不改变世界。
3. 墙跳增加客户端可重绑的 Shift 默认键位映射。玩家在空中按住该键并贴近可碰撞墙面时触发，朝上并向离墙方向弹开；未按住键或不在墙边时不触发。仅排除飞行、鞘翅、水中及攀爬等与墙跳冲突的状态，不额外限定每次滞空次数；触发间隔由接触墙面和离墙状态自然控制。
4. 按项目现有输入及事件模式接入机制，参考 `FlywheelDashClient.java` 的可重绑键位注册及 `MovementTweaks.java` 的移动状态判断。方块放置沿用原版交互链路和服务端校验，墙跳速度修改需在多人环境保持服务端同步。
5. 在配置界面补齐对应名称和说明，保持各语言 JSON 有效。

## 验证

- 运行 `./gradlew compileJava`。
- 校验修改过的语言 JSON。
- 游戏内验证走搭仅在合法位置放置且正常消耗物品，配置关闭后不介入原版放置。
- 验证墙跳按住重绑键贴墙触发、离墙弹跳、落地重置、单次滞空不重复触发，且配置关闭及排除状态下不触发。
- 如有多人环境，验证服务器端校验和移动/放置同步。
