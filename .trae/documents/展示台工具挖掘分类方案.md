# 展示台工具挖掘分类方案

## 背景

展示台目前只有硬度，没有工具分类，因此镐、斧无法按材质获得对应的加速挖掘。需求是：石头类展示台使用镐，木头类展示台使用斧；雪砖和冰砖展示台归入石头类。

## 实施方案

1. 在 `EndboundEmber.java` 的展示台主方块和材质变种注册属性中加入 `.requiresCorrectToolForDrops()`，让工具分类规则同时影响展示台掉落行为；不增加木镐、石镐或铁镐等级限制。
2. 更新 `data/minecraft/tags/block/mineable/pickaxe.json`：加入基础展示台 `display_pedestal`、全部石材/砖材/矿物/铜材展示台变种，以及 `packed_ice_brick_display_pedestal`、`snow_brick_display_pedestal`。雪砖、冰砖展示台明确使用镐。
3. 更新 `data/minecraft/tags/block/mineable/axe.json`：加入橡木、云杉、白桦、丛林、金合欢、深色橡木、红树、樱花、竹、绯红、诡异和竹马赛克展示台变种。
4. 保持现有 `.strength(6.7F, ...)` 不变，避免改变展示台基础硬度与爆炸抗性；不修改 `DisplayPedestalBlock.java`。

## 验证

运行 `./gradlew compileJava --no-configuration-cache -q`，解析两个 JSON 标签，检查每个展示台 ID 恰好归入镐或斧其中一类，并确认雪砖、冰砖位于镐标签。进入游戏分别用镐、斧和错误工具测试挖掘速度与掉落行为。
