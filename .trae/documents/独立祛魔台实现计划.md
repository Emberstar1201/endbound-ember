# 独立祛魔台实现计划

## 摘要

移除本项目中砂轮附魔转移相关实现，新增独立祛魔台方块及其 GUI。玩家将附魔物品放入输入槽后，可一次提取该物品上全部可转移附魔为附魔书；原物品返还，并保留不可转移的诅咒附魔。

## 当前状态分析

- 项目使用 Minecraft 1.21.1、NeoForge 21.1.262、Java 21。
- `EndboundEmber.java` 集中注册方块、方块物品、方块实体及菜单类型；展示台代码可供交互方块和方块实体注册参考。
- 当前没有方块容器菜单和对应屏幕的完整范例。伙伴菜单与屏幕注册可参考菜单类型注册、`AbstractContainerMenu`、槽位、快速移动及 `RegisterMenuScreensEvent` 的接入方式。
- 旧砂轮功能由三个 Grindstone Mixin、Mixin 配置条目、Config 配置项、四种语言文本以及中英文 README 描述构成。当前 Mixin 实际行为与部分旧说明不一致；本次按“砂轮相关的全部删除”处理，不保留砂轮附魔转移路径。
- 方块资源采用 `assets/endbound_ember/blockstates`、`models/block`、`models/item`、`textures/block`，掉落表位于 `data/endbound_ember/loot_table/blocks`。

## 方案与决定

1. GUI 输入一个待处理物品，输出槽展示并领取一次性提取结果：原物品及一本附魔书。空白书和青金石作为材料槽；每次成功领取结果消耗一本书和一个青金石。
2. 一次提取物品上全部非诅咒附魔；诅咒留在原物品上，不生成诅咒附魔书。若没有可提取附魔，则无结果。
3. 祛魔不消耗经验或物品耐久。输出领取必须在服务端重新验证输入与材料；成功时才扣材料、更新原物品并发出结果，避免预览与实际结算不一致。
4. 采用独立方块及 GUI，不再修改原版砂轮行为。方块容器应正确保存槽内物品；方块破坏时掉落槽内物品，GUI 关闭及快速移动不能吞物品或复制结果。
5. 完整删除三个砂轮 Mixin、`endbound_ember.mixins.json` 中对应配置、Config 中旧砂轮开关、四种语言中对应配置名和提示文本，以及中英文 README 中的旧砂轮描述。新祛魔台不沿用仅为旧砂轮机制存在的开关。

## 计划变更

### 旧砂轮功能清理

- `src/main/java/com/emberstar/endbounember/mixin/GrindstoneBookMixin.java`：删除旧砂轮附魔结果预览注入。
- `src/main/java/com/emberstar/endbounember/mixin/GrindstoneBookInputSlotMixin.java`：删除旧砂轮输入槽限制注入。
- `src/main/java/com/emberstar/endbounember/mixin/GrindstoneBookResultSlotMixin.java`：删除旧砂轮结果槽领取注入。
- `src/main/resources/endbound_ember.mixins.json`：移除上述三个 Mixin 类条目。
- `src/main/java/com/emberstar/endbounember/Config.java`：移除专用于砂轮附魔书转移的配置项及注册。
- `src/main/resources/assets/endbound_ember/lang/{zh_cn,zh_tw,zh_hk,en_us}.json`：移除旧配置项名称和说明。
- `README.md`、`README_EN.md`：删除旧砂轮工作流介绍，改为介绍独立祛魔台。

### 新增祛魔台

- `src/main/java/com/emberstar/endbounember/EndboundEmber.java`：按现有 DeferredRegister 模式注册祛魔台方块、方块物品、方块实体类型和菜单类型。
- 新增 `block` 下祛魔台方块及方块实体实现：方块交互打开菜单；方块实体保存输入、材料及输出容器状态，并在破坏时返还容器物品。
- 新增祛魔台菜单实现：定义输入/书/青金石/结果槽、结果预览和服务器端结算、背包快速移动及菜单有效性检查。
- 新增客户端祛魔台屏幕，并在 `src/main/java/com/emberstar/endbounember/client/ModClientEvents.java` 注册菜单屏幕。
- 新增对应 blockstate、方块与物品模型、纹理、掉落表，以及四种语言的方块名和必要 GUI 文本。
- 更新中英文 README，说明祛魔台的新操作方式及提取规则。

## 验证

- 运行 `./gradlew compileJava` 和资源处理/打包相关任务，确认注册与资源可编译加载。
- 检查所有 JSON 文件格式及引用的模型、纹理、掉落表路径。
- 确认 Mixin 配置和源码中不再残留旧砂轮功能类名或配置键。
- 在开发客户端检查方块放置、打开 GUI、槽位显示、附魔书预览与领取。
- 验证多项非诅咒附魔一次全部转移、诅咒仍留在原物品、书和青金石仅在成功领取时扣除、无可转移附魔时无结果。
- 验证输出槽满、Shift-click、关闭界面及破坏祛魔台时输入/输出不丢失且不复制。

## 范围说明

- “全部附魔”指一次处理所有非诅咒附魔；诅咒保留在原物品上，不作为输出。
- 书和青金石的数量按每次提取各一个设定；此成本是为补齐未指定规则所作的计划默认值，实施前可在审阅时调整。
- 不包含砂轮的其他原版行为改动，不添加额外配置开关，不涉及无关的配置或 Zoom 功能。
