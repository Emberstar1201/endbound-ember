# 墓园结构与安心效果实施计划

## Context

用户提供的墓园结构 NBT 尺寸为 51×9×51，包含大量蜡烛和 barrel。需要将其接入游戏世界，在村庄附近低密度生成，并实现墓园战利品、安心效果及点燃全墓园蜡烛成就。结构模板放置需保留相对 Y=-3 的深度偏移；生成密度和检查范围需要兼顾性能。

## 实施方案

1. **结构资源与放置**
   - 将上传 NBT 复制为 `data/endbound_ember/structures/cemetery.nbt`，沿用模板资源命名方式，名称使用英文 `cemetery`。
   - 按 51×9×51 模板边界保留蜡烛相对坐标和结构尺寸，模板锚点 Y 偏移为 -3。
   - 审查 `structure_block` 和显式空气处理；放置时避免不必要空气写入/覆盖地形，限定在服务端主线程并确保涉及区块已加载。
   - 参考 `ZombieGirlCampEvents.java` 的延迟放置流程，但独立实现墓园生成逻辑，不修改丧尸娘营地既有生成行为。

2. **村庄附近、低密度生成**
   - 在候选区块中延迟检查周围村庄，墓园中心距村庄中心不超过约 64 格。
   - 每个村庄最多生成一座；以村庄位置/维度作为稳定候选依据，避免区块重复加载反复抽取。
   - 新增墓园 `SavedData` 保存维度、村庄位置、墓园原点、包围盒和生成状态；生成前查询已记录墓园，保证大型结构间距并拒绝重叠候选。
   - 生成候选过滤优先采用轻量距离和记录查询，昂贵的地形/村庄扫描仅在延迟任务执行，绝不为检测而强制加载远处区块。

3. **木箱战利品与烈士日记**
   - 模板放置后遍历结构范围内的 barrel 方块实体，初始化随机宝藏内容；只处理实际存在的容器，且记录初始化完成以防重载重填。
   - 对每座墓园至少一个容器强制写入一本烈士日记，随机宝藏仍按容器正常生成；日记内容通过 `WRITTEN_BOOK_CONTENT` 构造，参考 `ZombieGirl.java` 现有书籍实现。

4. **安心效果**
   - 通过服务端玩家 tick 检查玩家是否处于已登记墓园包围盒；进入范围授予自定义「安心」效果，离开或切换维度时结束墓园授予的效果。
   - 安心效果在服务端每 20 tick 恢复 1 点饥饿值、1 点饱和度和 1 点生命值；限制饥饿/饱和不超过原版上限，生命不超过最大生命值。
   - 使用墓园实例的空间索引或附近实例筛选，禁止每 tick 扫描结构体素或访问未加载区块。

5. **蜡烛成就**
   - 注册成就「回家了!」，描述「干了这杯酒，我们烈士陵园见」，沿用 `ModAdvancements` 和 advancement JSON 的既有注册/发放方式。
   - 监听玩家使用打火石点燃蜡烛的成功交互；仅检查相应墓园记录的 124 个蜡烛坐标，确认每个位置仍是墓园蜡烛且 `lit=true`。
   - 全部点燃后由最后点燃一根蜡烛的玩家获得成就，并持久化墓园完成状态，避免重复发奖。

## 关键文件

- `src/main/java/com/emberstar/endbounember/world/ZombieGirlCampEvents.java`：参考区块加载、延迟任务、结构模板放置和容器后处理，不改动营地行为。
- `src/main/java/com/emberstar/endbounember/world/ModAdvancements.java`：新增成就注册和手动发放入口。
- `src/main/java/com/emberstar/endbounember/entity/ZombieGirl.java`：参考书籍组件构造方式。
- `src/main/resources/data/endbound_ember/advancement/`：新增成就 JSON。
- `src/main/resources/assets/endbound_ember/lang/`：新增安心效果、成就和烈士日记本地化。
- `src/main/resources/data/endbound_ember/structures/cemetery.nbt`：墓园结构资源。
- 新增墓园专用生成事件、SavedData 与安心效果实现类，按现有包结构组织。

## 验证

- 运行 `./gradlew.bat compileJava --no-configuration-cache`，检查结构、效果与成就 API 编译。
- 校验结构尺寸、124 个蜡烛局部坐标、barrel 实际方块实体，以及 Y=-3 放置后地表深度。
- 在村庄范围内验证最多一座墓园；附近无村庄时不生成；区块卸载/重载和服务器重启后不重复生成、不重复填充容器。
- 确认每座墓园有随机宝藏且必有一本烈士日记；已打开容器不因重载被重置。
- 进入墓园时安心效果生效，按每秒各恢复 1 点；离开墓园或切换维度后停止。
- 逐根点燃蜡烛，部分点燃不发奖，全部 124 根点燃时仅最后点燃者获得一次成就；结构损坏或蜡烛被替换时不误判。
