# 终界之书建筑方块分区实施计划

## Context

终界之书（Patchouli 手册）目前没有建筑方块分类。用户希望将模组已添加的建筑方块纳入手册，并在右页展示对应合成配方。项目已有 `spotlight` 展示页与 `patchouli:crafting` 配方页的条目范式，可沿用。袪魔台目前未找到合成配方资源，因此不能在手册中引用不存在的配方。

## 推荐实施方式

1. **确定收录范围并盘点条目**
   - 以模组建筑方块创造标签和建筑方块注册为权威来源，收录其中所有已添加的可获取建筑方块，包括颜色/材料变体、竖半砖、展示台系列及袪魔台；不把仅用于功能而不属于建筑用途的物品加入。
   - 按方块家族组织手册条目；每条目左页展示代表性物品与变体说明，右页按真实配方逐页展示对应合成。避免漏掉变体，也避免为每个相同配方模式机械复制说明。
   - 盘点并标记无配方、多配方及仅有石切机配方的物品。引用现有配方资源，不制作与游戏配方不一致的手册配方。

2. **新增分类与条目资源**
   - 在 `assets/endbound_ember/patchouli_books/endbound_ember/{zh_cn,en_us,zh_tw,zh_hk}/categories/` 增加“建筑方块”分类，选择已存在的建筑方块作为图标。
   - 在四种语言对应 `entries/` 中创建同一组条目 ID；分类 ID、条目数量、页序和 recipe ID 保持一致，各语言标题与说明本地化。
   - 沿用既有 Patchouli 页面类型：左页 `patchouli:spotlight` 展示方块，右页 `patchouli:crafting` 引用真实配方 ID；多配方时增加配方页并标明来源（工作台或石切机）。

3. **处理袪魔台配方缺口**
   - 先确认袪魔台预期的工作台合成材料与配方形状。得到确认后，在 `data/endbound_ember/recipe/` 增加真实配方资源，并让袪魔台条目右页引用该 recipe ID。
   - 若袪魔台设计上不可合成，则需要用户确认改为右页用途/获取说明；不能伪造合成配方图。

4. **验证**
   - 检查所有条目引用的物品、分类和 recipe ID 均存在；四种语言的条目集合和页结构一致，JSON 均可解析。
   - 运行 `./gradlew build`。
   - 若开发环境安装 Patchouli，启动游戏确认分类可见、各页配方图可加载，袪魔台配方可实际合成；Patchouli 为可选依赖时需确认缺少它不会影响模组启动。

## 关键文件

- `src/main/java/com/emberstar/endbounember/EndboundEmber.java`：建筑方块创造标签、材料家族及袪魔台注册的权威来源。
- `src/main/resources/assets/endbound_ember/patchouli_books/endbound_ember/`：四种语言的分类和条目资源；参考现有 `guide_book.json` 的 spotlight + crafting 页面结构。
- `src/main/resources/data/endbound_ember/recipe/`：核对并引用已有建筑配方；必要时新增已确认的袪魔台配方。
- `src/main/resources/data/endbound_ember/patchouli_books/endbound_ember/book.json`：确认手册资源包配置，无需改变现有书籍入口。

## 待确认事项

袪魔台目前没有合成配方 JSON。需要确认它的合成材料与工作台配方；若暂时没有预设，实施时先提交配方方案供用户确认，再实现配方和手册配方图。
