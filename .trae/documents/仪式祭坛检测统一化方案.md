# 仪式祭坛检测统一化方案

## Context（背景）

玩家按照教程搭好展示台祭坛后，右键中心展示台却提示「结构不完整」，祭坛无法启动。现有实现里三种仪式各自手写一套扫描逻辑，判定条件严苛且相互不一致，失败时多数路径静默 `return null`，玩家拿不到任何可定位的反馈。

现状问题（均已在代码中确认）：

1. **多余展示台直接判负**：光环/晨曦会把中心半径 3 内任意一个空展示台或无关展示台当成「物品不符」而失败；Herobrine 更是「非四角出现展示台一律视为摆错」。
2. **展示台必须落在同心环的特定半径**：只支持固定半径，混搭（如四角在 ±2、边中点在 ±3）或新旧摆法混用即失败。
3. **只能右键中心展示台**：右键任一环绕展示台时，`tryStartRitual` 以被点击位置为中枢扫描，必然失败。
4. **取回拦截范围有误**：`findAltarCenter` 会返回半径 3 内任意一个成立的祭坛中心，哪怕被点击的展示台并不属于该祭坛，导致旁边无关展示台里的物品取不下来。
5. **底座校验无容错**：7×7 底座必须逐格满足（末地石 / 发光完整方块 / 亡灵底座），错一格、缺一格即失败。
6. **失败无提示**：光环与 Herobrine 分支完全没有日志，晨曦只写日志不提示玩家。

目标：把三种（以及以后新增的）仪式统一为「一份定义 + 一个扫描器」，并保证玩家摆错时能立刻看到具体是哪一格、缺什么。

## 方案

### 1. 新增统一定义与扫描器

新建 `src/main/java/com/emberstar/endbounember/block/RitualAltar.java`，包含：

- `Definition`：仪式种类、核心物品判定、可选环半径（1/2/3）、槽位模式（八格整环 / 仅四角）、每槽期望物品、底座判定谓词与底座半径。
- `Slot`：相对中心的 `(dx, dz)` 与期望物品（区分角/边）。
- `Match`：中心、环半径、环绕展示台坐标列表。
- `Issue`：失败点坐标 + 期望内容（用于提示）。
- 扫描入口：
  - `find(Level, BlockPos clicked)`：在点击位置周围 ±3 找所有放着核心物品的展示台，逐个尝试匹配；返回包含该展示台的有效祭坛（没有则返回诊断信息）。
  - `matchAt(Level, BlockPos center, Definition)`：按定义校验槽位与底座，忽略图纸以外的多余展示台。
  - `report(Player, List<Issue>)`：把第一处问题写到动作栏，并在问题坐标处播报提示粒子。

三种仪式的定义（与原版常量保持一致）：

| 仪式 | 核心物品 | 环绕槽位 | 每槽期望 | 底座 |
| --- | --- | --- | --- | --- |
| 光环 | 星尘手绳 | 半径 1/2/3 的完整八格环 | 虚无星尘 | 7×7 末地石（`center.below()`） |
| 晨曦护符 | 拂晓附魔书等仪式核心 | 半径 1/2/3 的完整八格环 | 四角星尘、四边烈焰粉 | 7×7 发光完整方块（排除红石灯） |
| Herobrine | 下界之星 | 半径 2/3 的四角 | 下界之星 | (2r+1)×(2r+1) 亡灵风格方块 |

新增仪式时只加一条 `Definition`，不再写新的扫描方法。

### 2. 改造 `DisplayPedestalBlock`

文件：`src/main/java/com/emberstar/endbounember/block/DisplayPedestalBlock.java`

- 删除 `findAltarCenter`、`scanAltar`、`scanHaloAltar`、`scanAmuletAltar`、`scanHerobrineAltar`、`isNecroBase`、`isValidAmuletBase`、`isBaseOf`（逻辑迁移进 `RitualAltar`）。
- `tryStartRitual`：先按被点击位置匹配；失败则调用 `RitualAltar.find` 找同一祭坛的核心展示台并以其为中心启动；仍失败时调用 `report` 输出第一处问题。
- `useItemOn` / `useWithoutItem` 的取回拦截改为「被点击展示台确实属于某个有效祭坛」才拦截。
- 启动/扣经验/动画/产物流程保持不变。

### 3. 语言文件

四份 `lang`（zh_cn / en_us / zh_tw / zh_hk）新增提示键：

- `block.endbound_ember.display_pedestal.issue_missing_pedestal`（缺少展示台，附坐标）
- `block.endbound_ember.display_pedestal.issue_wrong_item`（物品不符，注明需要什么）
- `block.endbound_ember.display_pedestal.issue_bad_base`（底座方块不符）

### 4. 容错规则（本次采纳）

- 图纸以外的多余展示台、空展示台一律忽略，不再判负。
- 环绕展示台支持半径 1/2/3 中的任意一种完整摆法（角与边中点在同一个半径上）。
- 底座仍须完整，但失败时精确指出第一处不合格坐标。
- 右键祭坛内任意一处展示台都能识别中心并启动仪式。

## 验证

1. `.\gradlew.bat build --console=plain -q` 通过，jar 复制到 `D:\PCL\.minecraft\versions\1.21.1-NeoForge_21.1.265\mods`。
2. 光环祭坛：7×7 末地石 + 星尘手绳 + 八格虚无星尘（分别测半径 1/2/3 三种摆法）均可启动；旁边多放一个空展示台仍可启动；拿掉任意一颗星或换成烈焰粉时，动作栏指出该坐标。
3. 晨曦祭坛：按教程外缘 8 格摆法可启动；右键任一环绕展示台也能启动；故意把一格底座换成非光源方块，动作栏指出该坐标。
4. Herobrine 祭坛：下界之星中心 + 四角下界之星（半径 2 与 3），亡灵底座可启动；边中点额外放展示台不再失败。
5. 取回：祭坛环绕位上的材料无法取回；祭坛旁边不属于该祭坛的展示台可以正常取回。
