# 原版附魔武器兼容优化计划

## Context

用户希望参考 Universal Enchants 为原版附魔扩展可用武器：锋利、亡灵杀手、节肢杀手可用于三叉戟；穿刺可用于剑；多重射击、快速装填可用于弓。新适用关系应独立于现有“更好的附魔优化”开关。

## 实施方案

1. 按 Minecraft 1.21.1 原版数据格式，仅覆写六个原版附魔定义中的 `supported_items` 和 `primary_items`，保留原版定义的等级、权重、成本、槽位及 `exclusive_set` 等其余字段。
2. 为穿刺剑、弓类多重射击/快速装填设置范围精确的 `endbound_ember` 物品标签；锋利/亡灵杀手/节肢杀手的三叉戟适用集合按定义引用现有武器标签或窄范围标签，避免扩大通用标签影响其他模组附魔。
3. 不修改 `BETTER_LUCK_ENCHANTMENT` 配置、`EnchantmentCompatibilityMixin`、`EnchantingTableRules` 或新增 Mixin。武器适用范围由数据定义控制，原有附魔互斥及附魔台过滤规则保持不变。
4. 确认 `primary_items` 也包括目标武器，使这些附魔可以进入附魔台候选；`supported_items` 包括目标武器，使其可经铁砧或命令附魔。

- 新增 `src/main/resources/data/minecraft/enchantment/smite.json`

## 验证

1. 执行 `./gradlew compileJava --offline -q`，确认代码和资源打包构建成功。
2. 启动开发客户端并检查数据包加载日志，确认所有原版附魔 JSON 字段、资源位置与标签引用有效。
3. 用 `/enchant` 和铁砧分别验证三叉戟锋利/亡灵杀手/节肢杀手、剑穿刺、弓多重射击/快速装填的适用性。
4. 在附魔台确认上述目标附魔能作为候选，并检查预览与应用结果一致。
5. 在“更好的附魔优化”开启和关闭时分别确认上述适用关系仍生效；确认原版互斥规则没有因本改动改变。
6. 实际测试新增组合的战斗/射击效果，尤其确认弓上的多重射击与快速装填行为符合预期。
