# 背包图腾与自动替换功能计划

## Context
用户希望增加两项可独立关闭的内置功能：玩家常规物品栏中的图腾无需手持即可在致死伤害时触发；正在主手使用的工具耐久耗尽时，自动从物品栏换入同一物品类型的完好替代品。替代品的附魔或其他数据组件不同不应妨碍匹配。图腾搜索范围为主背包与快捷栏，不含末影箱、饰品栏及外部容器；自动替换范围仅为主手快捷栏槽位。

## 推荐实现
1. 在 `Config.java` 增加两个 COMMON 默认开启的独立配置开关，并在 `zh_cn.json`、`zh_tw.json`、`zh_hk.json`、`en_us.json` 中补齐名称和 tooltip。
2. 在 `EternalTotemEvents.onDeath` 扩展图腾候选搜索：维持虚空及绕过无敌伤害不触发；保持主/副手永恒图腾现有优先级，其次检查玩家主背包与快捷栏中的不死图腾或永恒图腾。背包图腾在被消耗的物品原槽减少一个；永恒图腾沿用现有生命回复、增益、耐久和图腾动画逻辑，不死图腾采用原版图腾效果。配置关闭时保留现有手持永恒图腾行为，仅禁用背包触发。
3. 自动替换仅作用于玩家主手快捷栏槽位。推荐在 `ItemStack#hurtAndBreak` 的损坏分支使用 Mixin，于堆栈即将损坏且持有者为玩家时检查主背包/快捷栏其他槽位；以相同 Item 类型作为匹配条件，不要求组件相同，并要求替代物尚未达到最大耐久。找到替代品后将其移入主手槽，由原耐久流程正常移除已损坏工具；无合格替代品、非玩家持有者或开关关闭时不改变原版流程。须基于 1.21.1 映射核对精确注入点并避免 `DualWieldCombat` 自行调用 `hurtAndBreak` 与原版调用的重复替换。
4. 新增的开关应影响背包图腾与自动替换各自行为，不改变现有永恒图腾手持能力或其他物品机制。

## 关键文件
- `src/main/java/com/emberstar/endbounember/Config.java`
- `src/main/java/com/emberstar/endbounember/item/EternalTotemEvents.java`
- 新增 `src/main/java/com/emberstar/endbounember/mixin/` 下的耐久耗尽 Mixin，并登记至 `src/main/resources/endbound_ember.mixins.json`
- `src/main/resources/assets/endbound_ember/lang/{zh_cn,zh_tw,zh_hk,en_us}.json`

## 验证
- 用 JDK 21 运行 `gradlew.bat compileJava`。
- 验证四份语言 JSON 可解析、配置键一致，Mixin 配置 JSON 正确。
- 游戏内验证：手持与背包图腾优先级及消耗、虚空伤害不触发、关闭开关后行为；主手工具损坏后只将同 Item 类型且耐久未耗尽的物品从常规物品栏换入当前槽，组件差异不阻止替换，关闭功能或无替代品时维持原版行为。
